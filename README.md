# Новое поколение — Brand Identity Case

Статический сайт, подготовленный для публикации через GitHub Pages.

## Публикация

1. Создайте репозиторий на GitHub.
2. Загрузите все файлы из этой папки в ветку `main`.
3. Откройте:
   Settings → Pages → Deploy from a branch → `main` → `/root`.
4. После публикации сайт будет доступен по адресу GitHub Pages.

Файл `.nojekyll` добавлен для корректной отдачи статических ресурсов.
